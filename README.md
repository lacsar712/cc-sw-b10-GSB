# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

顶栏「轨迹台」为近次偏差轨迹专页：按时间列近次已结案标称/实测点并标合格或超差，条数可选；可选对照点，差额由服务端计算下发；校准员可签发轨迹快照，签发时点集与差额即冻结，之后新结论只影响在线轨迹，历史副本不变。


## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 再提交超差样条，先待处理再出超差。
3. inspector 不能提交。
4. 顶栏进「轨迹台」：按时间列近次已结案点并标合格/超差，条数可切换；多投后与总览结论一致。
5. 选对照点后差额区显示服务端算出的标称/实测/偏差差额。
6. calibrator 可签发快照，inspector 看不到签发按钮且接口返回 403；两角色都能看轨迹与快照。
7. 签发后继续提交新笔，重开快照点集与差额仍停在签发版。
